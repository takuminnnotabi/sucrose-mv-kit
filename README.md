# 推し MV 壁紙キット

コードをコピーしたり、6 個のファイルを自分で作ったりする必要はありません。

## 最初にすること

1. **Sucrose Wallpaper Engine** をインストールして、一度開きます。
2. Sucrose の **「＋」→「YouTube」** で、推しの **プレイリスト URL** と好きなタイトルを入れて登録します。動画 1 本の URL ではなく、`list=` が入った URL を使います。
3. Windows 右下のタスクトレイで Sucrose のアイコンを右クリックし、**「終了」** を選びます。画面右上の × だけでは終了しません。
4. 配布 ZIP を右クリックして **「すべて展開」** します。ZIP の中から直接実行しないでください。
5. 展開したフォルダーの **「セットアップを開始.cmd」** をダブルクリックします。
6. 日本語の案内に従って進めます。足りない Python / Node.js は、確認後に winget で導入します。すでにあるソフトは導入し直しません。
7. **「セットアップ完了！」** が出たら Sucrose を開き直し、ライブラリで推しの壁紙を選び直します。

初回の準備や再生には数分かかる場合があります。準備中の黒い画面は閉じずに待ってください。
Node.js の導入では、Windows が管理者の許可を求める場合があります。winget がない PC では公式ダウンロードページを開きます。

## 使い始めたら

- **別の動画を見たい：** デスクトップの「壁紙動画をシャッフル」をダブルクリック。
- **Windows の右クリックから切り替えたい：** 背景のスライドショーを使っている場合は、デスクトップを右クリック →「次のデスクトップの背景」を押します。選んでいる MV 壁紙の一覧から、別の動画をランダムに選びます。背景のスライドショーが自動で次へ進んだ場合も反応します。
- **新しく追加された動画を確認したい：**「壁紙プレイリストを更新」をダブルクリック。起動時と約 1 時間ごとにも確認します。
- **別の推しのプレイリストも登録したい：** Sucrose の「＋」→「YouTube」で新しく登録 →「壁紙プレイリストを更新」→ Sucrose を開き直して、その壁紙を選び直します。
- **URL を変えたい：** Sucrose で新しい URL のテーマを作り、上の手順で選び直す方法が簡単です。

補助ファイルは自動で **「ドキュメント」内の「sucrose-mv-kit」** にコピーします。このフォルダーは、壁紙を使っている間は移動・削除しないでください。ダウンロードした ZIP と、最初に展開した元のフォルダーは、セットアップ完了後に削除してかまいません。

## 以前の配布 ZIP で設定済みの人が更新するとき

この方法は、この配布キットを使って **「ドキュメント」内の「sucrose-mv-kit」** に設定した人向けです。Lively / Sucrose の内部フォルダーなど、別の場所に作った環境へは上書きしないでください。

1. 念のため、ドキュメント内の「sucrose-mv-kit」フォルダーを別の場所へコピーしてバックアップします。
2. 新しい ZIP を「すべて展開」します。
3. 展開したキットの **11 個のファイル** を、ドキュメント内の既存「sucrose-mv-kit」へコピーし、「ファイルを置き換える」を選びます。
4. **すぐに Windows を再起動**します。コピーが終わってから再起動するまでは、シャッフルやプレイリスト更新のボタンを押さないでください。
5. Sucrose のライブラリで、使いたい MV 壁紙を選び直します。

**「セットアップを開始.cmd」をもう一度実行する必要はありません。** 既存フォルダーを削除して置き換えると実行環境が失われるため、ファイルの上書きコピーを使います。ZIP に `.venv`、設定、ログは含まれないので、既存のものをそのまま残します。

## Windows の右クリックから動画を変える準備

Windows の「次のデスクトップの背景」が見当たらない場合は、Windows の「設定」→「個人用設定」→「背景」で「スライドショー」を選び、写真が 2 枚以上あるフォルダーを指定してください。MV の表示は Sucrose が担当し、この Windows の操作を補助プログラムが検知します。
切り替え時は壁紙の再生エンジンを再起動するため、映像が一時的に消えることがあります。動画の取得と読み込みにかかる時間は環境によって変わり、瞬時に切り替わる保証はありません。切り替え前に一時停止していた場合は、一時停止を保ちます。

## 止まったとき

- **Sucrose が起動中と言われた：** タスクトレイから「終了」してからやり直します。
- **プレイリストが 0 件と言われた：** Sucrose の YouTube テーマに、公開プレイリストの URL を登録してください。
- **既存の壁紙補助が動いていると言われた：** すでにセットアップ済みの可能性があります。このキットは重ねて実行せず、いつもの「壁紙プレイリストを更新」を使ってください。
- **ソフトの導入に失敗した：** 公式サイトから Python 3 / Node.js LTS を導入し、Windows にサインインし直してからやり直します。
- **その他のエラー：**「ドキュメント」→「sucrose-mv-kit」→ **「setup.log」** に詳しい記録があります。
- **Windows の「次のデスクトップの背景」で切り替わらない：** Sucrose で MV 壁紙を選び直します。選んでいる一覧に動画が 1 本しかないと、別の動画へは切り替えられません。動作の記録は `desktop-next-status.json`、再生補助の記録は `helper-events.log` です。

## このキットについて

無料の Sucrose、Python、Node.js、yt-dlp を組み合わせた補助コードです。Sucrose 公式の機能追加や公式配布物ではありません。
動画は YouTube からストリーミングし、MV 本体を保存するダウンロード処理は行いません。再生には通信と一時的なバッファを使います。
取得可能な最大の解像度を選ぶ仕組みなので、元の動画が 1080p なら 1080p です。すべての動画を 4K にすることはできません。

元の Sucrose 設定は「before-mv」が付いたファイルへバックアップします。セットアップは起動中の Sucrose を強制終了しません。「次のデスクトップの背景」の検知時には、選択済みの壁紙の再生エンジンを確認して再起動します。Windows の恒久的な PowerShell ポリシーを変更せず、このセットアップのプロセスだけでスクリプトを実行します。

元の再生方式は Windows 11 / Sucrose 26.7.5.0 の実環境で確認しています。ただし、**この配布用の入口による新品 PC への導入を、最初から最後まで実機で試したわけではありません。** 構文と、空の一覧・取得失敗時に設定を変えない動作を確認した版です。
