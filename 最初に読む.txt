推し MV 壁紙キット：コードをコピペする必要はありません！

1. Sucrose の「＋」→「YouTube」で推しのプレイリストを登録。
2. 右下のタスクトレイで Sucrose を右クリック→「終了」。
3. ZIP を「すべて展開」したフォルダーから
   「セットアップを開始.cmd」をダブルクリック。
4. 日本語の画面案内に従う。完了したら Sucrose を開き直す。
5. ライブラリで推しの壁紙を選び直す。

初回は数分かかる場合があります。
不足する Python / Node.js は確認してから導入します。

セットアップ後、ドキュメント内の sucrose-mv-kit を移動・削除しないでください。
すでに壁紙補助を使っている PC には重ねて実行できません。

以前の配布 ZIP を使った人の更新：
ドキュメント内の sucrose-mv-kit をバックアップし、
新しい ZIP の11ファイルを既存フォルダーへ上書きコピー。
すぐ Windows を再起動し、Sucrose で壁紙を選び直します。
セットアップの再実行や、既存フォルダーの削除は不要です。
Lively/Sucrose の内部など別の場所へ作った環境には上書きしません。

別の動画を見る：デスクトップの「壁紙動画をシャッフル」。
Windows の背景スライドショー設定済みなら、
右クリックの「次のデスクトップの背景」でも切り替えられます。
切り替え前の一時停止は保ちます。読み込みには時間がかかる場合があります。

詳しい使い方と、止まったときの対処は「README.md」に書いてあります。
配布用の初回導入は、新品 PC での通し実機確認をまだしていません。
